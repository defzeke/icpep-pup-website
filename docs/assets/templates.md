## Post dimensions

| Format | Ratio | Pixel size |
| --- | --- | --- |
| Regular | 1:1 | 2048 × 2048 |
| Portrait | 4:5 | 2160 × 2700 |

These are **social templates**, not web layouts. Two consequences for the site:

- An **Events** card for a social post should reserve the 1:1 ratio; use the 4:5 for
  story-style placements. See [../sections/events/README.md](../sections/events/README.md).
- A **Gallery** grid mixing both ratios needs a defined strategy (fixed square crop, or
  masonry). The brand does not specify one — see that section's open questions.
